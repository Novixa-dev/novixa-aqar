## 0. كيف تستخدم هذه الخطة

كل بند يبدأ بمربع `[ ]`. ضع `[x]` عند النجاح، أو `[!]` عند وجود مشكلة ثم
سجّلها في **القسم 12** بالتنسيق المطلوب.

**قاعدة حاكمة:** لا تكتفِ بأن الصفحة «فُتحت». افتح **أدوات المطوّر**
(`F12`) على تبويب **Console** و**Network** طوال الفحص. صفحة تفتح وهي
مليئة بأخطاء في الـ Console ليست صفحة ناجحة.

**تصنيف الخطورة:**

| الرمز | المعنى | هل يمنع العرض؟ |
|---|---|---|
| **P0** | خطأ فادح: صفحة بيضاء، 500، تسريب بيانات، فقدان صلاحيات | **نعم — يمنع فورًا** |
| **P1** | مسار رئيسي معطّل (تسجيل دخول، بحث، حجز) | **نعم** |
| **P2** | خلل ظاهري أو ترجمة ناقصة أو اتجاه خاطئ | لا، لكن يُصلَح قبل العميل |
| **P3** | تحسين شكلي أو صياغة | لا |

## 4. المرحلة الثانية — اللغة والاتجاه (RTL / LTR)

العربية هي اللغة الأساسية. هذا القسم من أكثر الأقسام كشفًا للأخطاء.

### 4.1 التبديل

- [ ] زر تبديل اللغة ظاهر في كل صفحة.
- [ ] `/lang/en` يحوّل الموقع للإنجليزية ويبقيك في نفس الصفحة.
- [ ] `/lang/ar` يعيده للعربية.
- [ ] اللغة **تبقى محفوظة** بعد التنقل بين الصفحات وبعد إعادة التحميل.

### 4.2 في الوضع العربي (RTL)

- [ ] `<html dir="rtl">` (تحقق من عنصر html في أدوات المطوّر).
- [ ] النص يبدأ من اليمين، والقائمة الرئيسية على اليمين.
- [ ] الأيقونات والأسهم معكوسة بالاتجاه الصحيح (سهم «التالي» يشير لليسار).
- [ ] الجداول تبدأ أعمدتها من اليمين.
- [ ] النماذج: التسميات على اليمين وحقول الإدخال محاذاة صحيحة.
- [ ] **لا نص إنجليزي متسرّب** في واجهة عربية.
- [ ] **لا مفاتيح ترجمة خام** ظاهرة مثل `messages.welcome` أو `properties.title`.
- [ ] الأرقام والتواريخ مقروءة ولا تنقلب بشكل خاطئ.

### 4.3 في الوضع الإنجليزي (LTR)

- [ ] `<html dir="ltr">`.
- [ ] لا نص عربي متسرّب في واجهة إنجليزية.
- [ ] التخطيط لا ينكسر عند التبديل ذهابًا وإيابًا.

### 4.4 اختبار التبديل تحت الضغط

- [ ] بدّل اللغة **داخل** صفحة تفاصيل عقار — يجب ألا تفقد العقار.
- [ ] بدّل اللغة وأنت مسجّل دخول — يجب ألا تُخرجك من الجلسة.
- [ ] بدّل اللغة داخل إحدى لوحات Filament.

## 7. المرحلة الخامسة — حالات الاستخدام الكاملة

نفّذ كل سيناريو من أوله لآخره كما يفعل مستخدم حقيقي.

### 7.1 زائر يبحث عن عقار
- [ ] ادخل الرئيسية → ابحث عن مدينة → افتح نتيجة → شاهد الصور →
      أضفه للمفضلة → اطلب معاينة.

### 7.2 مشترٍ
- [ ] سجّل الدخول → تصفّح العقارات → قارن عقارين → احجز موعد معاينة →
      تحقق من ظهور الحجز في لوحتك.

### 7.3 بائع
- [ ] سجّل الدخول → أضف عقارًا جديدًا → **ارفع صورة** → استخدم
      **توليد الوصف** → احفظ → تحقق أن العقار ظهر في الموقع العام بصورته.

### 7.4 مالك عقار
- [ ] سجّل الدخول → أضف عقارًا للإيجار → أنشئ عقد إيجار → اربطه بمستأجر →
      تحقق من ظهور العقد للطرفين.

### 7.5 مستأجر
- [ ] سجّل الدخول → اعرض عقد الإيجار → قدّم طلب صيانة → تحقق من ظهوره
      لدى المقاول.

### 7.6 مقاول
- [ ] سجّل الدخول → افتح طلب الصيانة → غيّر حالته → تحقق أن المستأجر
      يرى التحديث.

### 7.7 وكيل
- [ ] سجّل الدخول → اعرض العملاء المحتملين → افتح موعدًا → سجّل متابعة.

### 7.8 موظف ومدير
- [ ] افتح عددًا من الموارد الـ 32 في لوحة الموظف — أنشئ وعدّل واحذف سجلًا.
- [ ] في لوحة المدير: المستخدمون، الأدوار، الصلاحيات، الإعدادات.

## 8. المرحلة السادسة — الخدمات الخارجية المضافة حديثًا

- [ ] أعد تحميل الصفحة — الصور تأتي من الكاش (حالة 304 أو `from cache`).
- [ ] **ارفع صورة جديدة** من لوحة البائع أو المدير → تظهر فورًا في الموقع.
- [ ] ارفع مستندًا (PDF) من لوحة تتيح ذلك → يُحفَظ بلا خطأ.
- [ ] **فحص أمني:** انسخ رابط صورة وافتحه في نافذة متخفية — يجب أن يعمل
      (الصور عامة). ثم حاول تخمين رابط مستند خاص عبر `/media/` — يجب
      أن **لا يعمل** (المستندات ليست على هذا المسار).

### 8.2 البريد الإلكتروني

- [ ] املأ نموذج `/contact` وأرسله.
- [ ] تحقّق من وصول رسالة إلى `ak01redwan@gmail.com` (وافحص مجلد
      **الرسائل غير المرغوبة** — المرسل الحالي `onboarding@resend.dev`).
- [ ] الرسالة تحتوي بيانات النموذج فعليًا لا قالبًا فارغًا.
- [ ] لا تظهر رسالة خطأ للمستخدم بعد الإرسال.

> **قيد معروف:** قبل توثيق النطاق، لا يستطيع Resend الإرسال إلا إلى بريد
> مالك الحساب. إشعارات الحسابات التجريبية (`@darhadhramaut.ye`) لن تصل

### 8.3 الذكاء الاصطناعي

- [ ] افتح `/submit-property` → املأ الحقول → اضغط **توليد الوصف**.

- [ ] جرّب الدخول بكلمة مرور خاطئة → رسالة خطأ، لا انهيار.
- [ ] جرّب الدخول الخاطئ عدة مرات متتالية → يجب أن يحدّ النظام المحاولات.
- [ ] ارفع ملفًا بامتداد غير مسموح في نموذج الصور → يُرفض برسالة واضحة.
- [ ] اكتب نصًا طويلًا جدًا في حقل نصي → لا ينهار.
- [ ] اضغط زر الإرسال مرتين بسرعة → لا يُنشئ سجلين مكرّرين.

## 11. المرحلة التاسعة — فحص أمني سريع

- [ ] كل الصفحات تُفتح عبر **HTTPS** بقفل أخضر.
- [ ] لا تظهر أي مفاتيح أو كلمات مرور في مصدر الصفحة (`Ctrl+U`) أو Console.
- [ ] `APP_DEBUG` غير مفعّل في الإنتاج: صفحة الخطأ **لا** تعرض أثر التنفيذ
      (stack trace) أو أسماء ملفات الخادم.
- [ ] تسجيل الخروج يُبطل الجلسة فعليًا.
- [ ] لا تحتوي الروابط على معرّفات حسّاسة يمكن تخمينها للوصول لبيانات غيرك.

## 12. تسجيل النتائج

سجّل كل مشكلة بهذا التنسيق بالضبط:

```
[الخطورة] المسار — وصف المشكلة
الخطوات: 1) ... 2) ... 3) ...
المتوقع: ...
الفعلي: ...
المتصفح/المقاس: ...
اللغة: عربي / إنجليزي
لقطة شاشة: ...
```

**مثال:**

```
[P1] /properties/12 — صورة العقار لا تظهر
الخطوات: 1) افتح /properties 2) اضغط على أول عقار
المتوقع: ظهور معرض الصور
الفعلي: مربع رمادي، وفي Network الطلب يعيد 404
المتصفح/المقاس: Chrome / 1440px
اللغة: عربي
```
