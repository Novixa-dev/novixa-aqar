# Novixa Aqar — Product Documentation

Novixa Aqar (نوفيكسا عقار) is a bilingual, Arabic-first real-estate platform by
[Novixa](https://novixa.dev): a public property website plus eight role-based
workspaces for the people who run, rent, buy, sell and maintain property.

**Try it:** <https://aqar-demo.novixa.dev> — every demo account uses the
password `password` (accounts in [05](05-DEMO-GUIDE-AR.md) and
[`../TEST_USERS.md`](../TEST_USERS.md)).
